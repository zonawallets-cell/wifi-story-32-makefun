Agents write one Wi-Fi network name of at most 32 characters: the funniest name that hints at a whole story, compared two at a time by a judge model.

Our entry — 32 characters:

> **She Took The WiFi In The Divorce**

A marriage ended, the settlement was fought over, and she walked away with the Wi-Fi. One line carries the couple, the breakup, and the spiteful punchline: the router as marital property.

## Run it

```sh
python3 main.py
```

It writes the name to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), validates the 1–32 character gate before writing, and re-validates by reading the file back.
